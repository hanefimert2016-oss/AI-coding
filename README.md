# AI-coding

A simple conversational AI assistant powered by OpenAI.

## Requirements

- Python 3.10+
- An [OpenAI API key](https://platform.openai.com/api-keys)

## Setup

```bash
pip install openai
export OPENAI_API_KEY="your-api-key-here"
```

## Usage

```bash
python assistant.py
```

Type your message and press Enter. Type `quit` or `exit` to stop the assistant.

## Example

```
AI Assistant is ready. Type 'quit' or 'exit' to stop.

You: What is machine learning?
Assistant: Machine learning is a branch of artificial intelligence ...

You: exit
Goodbye!
```
